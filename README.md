## 🚀 核心技术亮点 (Technical Highlights)

- **后端**: FastAPI + PostgreSQL (pgvector) 实现秒级位次检索与生涯语义匹配。
- **前端**: Next.js 14 响应式 Web + React Native 移动 App 双端交付。
- **算法**: 位次-扩招相关性修正模型，将预测误差控制在 ±5 排名以内。
